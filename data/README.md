# Input data

Filename: `noshowappointments-kagglev2-may-2016.csv`.

The analysis uses the exact CSV uploaded by Lamiae Abbouyat with her Udacity project. The GitHub ZIP excludes the raw CSV; copy your original CSV into this data folder to reproduce the analysis. It has 110,527 rows and 14 columns. No substitute dataset was used. `results/provenance.json` records the SHA-256 checksum and analysis environment.

The original public source URL and redistribution terms were not included in the uploaded files and have not been independently verified. The repository ignore rules exclude raw CSV files from Git uploads. Keep the supplied CSV locally to reproduce this analysis; add a verified original source and license before distributing raw data publicly.

`No-show`: Yes = missed; No = attended. Scheduling lead time means days from booking to appointment, not time spent waiting at a clinic.
